# 11 · Orzu Medical · Урок 1 «Строим мини-проект с ИИ» — заметки для тренера

Урок в LMS: `apps/api/src/db/workbook-orzu-week1.ts` (RU + UZ), слайды —
`apps/web/public/workbook/orzu/step-0..7.png`. Пример на всех шагах — трекер
заявок клиники.

## Структура
1. Идея на одну страницу — пользователь, проблема, метрика успеха → `docs/IDEA.md`
2. Мини-PRD вместе с ИИ — MVP, что не делаем, критерии приёмки → `docs/PRD.md`
3. Подготовка проекта — приватный репозиторий в GitHub, папка `docs/`, `PRD.md` как правила
4. План и маленькие задачи → `docs/TASKS.md` (каждая проверяется за 5 минут)
5. Первый цикл — задача агенту → проверка → commit
6. Типичные ошибки вайбкодера
7. Итоговый чеклист + задача недели

На каждом шаге в уроке есть настоящий промпт (кнопка «Копировать») и пример
файла, затем упражнения со сдачей «Сдано ✓».

## Запись видео-демонстрации
- Показываем **реальные промпты и файлы**, а не слайды: VS Code, чат с Claude, GitHub.
- Говорим **простым языком** — так, чтобы понял не-программист.
- **Шрифт крупнее**: в VS Code `Ctrl/Cmd + =` 3–4 раза, терминал и чат — тоже.
- **Личные данные и ключи убрать с экрана**: отдельный тестовый аккаунт GitHub,
  никаких `.env`, токенов, телефонов и данных пациентов в кадре.
- **Ожидание генерации вырезаем или ускоряем** (×4–×8) при монтаже.
- Ссылку на видео добавить в урок (редактор → блок «Кнопка/видео», YouTube).
